# Lapor-Kota-Lapor-Desa
LaporKota adalah platform berbasis web yang memudahkan warga untuk melaporkan dan memantau masalah lingkungan atau fasilitas umum—seperti jalan rusak dan penumpukan sampah—secara real-time.

**Tech Stack**:
**Frontend**: [Contoh: HTML5, CSS, js]
**Database**: [PostgreSQL]

clone repository ini
git clone https://github.com/fawazz-ibd/Civic-Report.git

masuk ke direktori project
cd Civic-Report

Install dependencies
npm install

Jalankan project:
npm run start
*(atau sesuaikan dengan perintah untuk menjalankan project, misal: npm run dev / Live Server)*
